# Nupixel

Мобильная творческая студия для Android (растр → слои → кисти → вектор → анимация → 3D).
Проект развивается поэтапно; ниже — честный статус.

## Статус: этап 1 (код написан, **не собирался и не запускался**)

Код этапа 1 написан в среде без Android SDK, Gradle и доступа к сети. Ни сборка, ни юнит-тесты,
ни запуск на устройстве **не выполнялись**. В нём возможны ошибки компиляции — первым шагом нужно
собрать проект и исправить их.

## Сборка

Требуется JDK 17+ и Android SDK (платформа 34).

```bash
# один раз: создать gradle wrapper (jar не входит в репозиторий)
gradle wrapper --gradle-version 8.7
./gradlew testDebugUnitTest   # юнит-тесты формата
./gradlew assembleDebug       # APK: app/build/outputs/apk/debug/app-debug.apk
```

Либо откройте папку в Android Studio (Koala или новее).

## Ограничения этапа 1

- Размер холста до 4096×4096, импорт — до 16 Мпикс (крупные изображения уменьшаются при импорте).
  Причина: аппаратная отрисовка Android не принимает битмапы свыше 100 МБ; тайловый рендеринг снимет лимит.
- Пиксели слоёв хранятся в памяти целиком; бюджет — 60% кучи приложения.
- DPI хранится в проекте, но не записывается в экспортируемые PNG/JPEG/WebP.
- Встроенные ICC-профили при импорте не сохраняются; цвет считается sRGB.
- Экспорт JPEG заливает прозрачность белым.
- Иконки — минимальный набор Material Core; собственный набор иконок запланирован.
